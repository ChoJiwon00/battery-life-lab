# 공부 노트

이 폴더에는 내가 궁금했던 기술 질문을 AI(Claude)와 이야기하며 특허와 논문으로 확인한 기록을 모아요.

- 질문, 처음 생각, 판단은 내 것이에요. AI는 설명하고 반문했고, 대화를 노트로 정리했어요.
- 노트마다 '내 생각'과 '확인한 내용(AI 설명)'을 나눠 적어요. AI가 먼저 던진 질문에 답한 곳은 그 질문을 앞에 적어요.
- AI 설명의 숫자와 특허 문장은 AI가 논문·특허 원문과 대조했고, 출처를 노트 맨 아래에 달아요.
- 특허 숫자는 [Patent Radar 청구항 숫자 지도](https://chojiwon00.github.io/patent-radar/claims.html)와 같은 자료예요.
