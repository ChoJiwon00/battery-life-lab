# 데이터 카드 · Severson 124셀 충방전 데이터 (정리본)

이 저장소의 `battery_lab`이 원본에서 만드는 정리된 데이터셋(`data/processed/`)의 설명서예요.
무엇이 들어 있고, 어떻게 만들었고, 무엇을 조심해야 하는지 한곳에 모았어요.
품질 점검의 세부 숫자는 [데이터 품질 리포트](data_quality.md)에, 만드는 과정에서 틀렸던 점은 [시행착오 기록](troubleshooting.md)에 있어요.

---

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 원본 | Toyota Research Institute, [Data-driven prediction of battery cycle life before capacity degradation](https://data.matr.io/1/projects/5c48dd2bc625d700019f3204) |
| 라이선스 | CC BY 4.0. 쓸 때는 아래 논문을 인용해요 |
| 셀 | A123 Systems APR18650M1A · LFP/흑연 원통형 · 공칭 1.1Ah · 3.3V |
| 시험 조건 | 30°C 챔버 · 급속충전 조건 69가지(0→80%) 뒤 1C CC-CV · 방전은 모두 4C · 2.0\~3.6V |
| 셀 수 | **124개** (b1 41 · b2 43 · b3 40) |
| 나누기 | 학습 41 · 테스트 43 · 2차 테스트 40 (논문과 같음) |
| 수명 | 148 \~ 2,237사이클 (중앙값 736.5) · 수명 = 용량이 처음 0.88Ah(공칭의 80%) 미만이 된 사이클 |
| 크기 | 원본 .mat 3개 7.70GB → 정리본 약 1GB. 여기서 GB는 1,024³바이트(엄밀히는 GiB)로, `info`·`download` 명령의 표시와 같은 단위예요. 원본 합계 8,269,341,808바이트를 1,000³바이트로 세면 8.27GB예요 |

## 만드는 방법

```
.venv\Scripts\python.exe -m battery_lab download --yes   # 원본 3개 배치 (7.70GB, 1GB = 1,024³바이트)
.venv\Scripts\python.exe -m battery_lab extract          # 셀마다 값 추리기 → data/interim/
.venv\Scripts\python.exe -m battery_lab assemble         # 논문 규칙으로 124개 셀 → data/processed/
.venv\Scripts\python.exe -m battery_lab report           # 품질 점검·검증 → docs/data_quality.md
```

| 규칙 | 대상 | 이유 |

| 뺌 | b1c8 · b1c10 · b1c12 · b1c13 · b1c22 | 80%에 닿기 전에 시험이 끝남 |
| 뺌 | b3c2 · b3c23 · b3c32 · b3c37 · b3c42 · b3c43 | 저자 코드 주석은 '잡음 채널'. 그중 b3c23·b3c32는 80%에 닿기 전에 시험이 끝남(원본 수명 값 없음) |
| 이어 붙임 | b2c7→b1c0 · b2c8→b1c1 · b2c9→b1c2 · b2c15→b1c3 · b2c16→b1c4 | b1에서 멈췄다가 b2에서 이어 시험한 같은 셀. 수명에 662 · 981 · 1060 · 208 · 482를 더함 |
| 나누기 | b1·b2를 합친 순서에서 1·3·5…83번째(0부터 세면 짝수 위치)와 마지막 84번째 셀 → 테스트, 2·4·6…82번째 → 학습, b3 전부 → 2차 테스트 | |

규칙의 출처: [저자의 데이터 정리 코드](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation) (`Load Data.ipynb`)

## 파일과 열

### `cells.csv` (셀마다 한 줄)

| 열 | 뜻 |
|---|---|
| `cell_id` | 셀 이름. `b1c0` = 1배치의 0번째 셀 |
| `batch` | `b1`(2017-05-12) · `b2`(2017-06-30) · `b3`(2018-04-12) |
| `policy` | 급속충전 조건. `6C(40%)-3C` = SOC 0\~40%는 6C, 40\~80%는 3C. b3는 끝에 `-newstructure`가 붙음 |
| `cycle_life` | 사이클 수명 |
| `n_cycles` | 기록된 사이클 수 |
| `split` | `train` · `test` · `secondary_test` |
| `merged_from` | 이어 붙인 셀의 원래 이름 (5개 셀만) |
| `seam_cycle` | 이어 붙인 쪽의 첫 사이클 (5개 셀만). 이음매 앞뒤로 용량이 최대 1.4% 바뀌어요 |

### `summary.csv` (사이클마다 한 줄)

| 열 | 단위 | 뜻 |
|---|---|---|
| `cycle` | | 사이클 번호 |
| `QD` · `QC` | Ah | 방전 · 충전 용량 |
| `IR` | Ω | 내부저항 (80% SOC에서 ±3.6C 짧은 펄스 10번 평균). 보통 0.013\~0.024Ω |
| `Tavg` · `Tmin` · `Tmax` | °C | 셀 겉면 온도. 열전대 접촉이 일정하지 않아 **참고용** (공식 설명) |
| `chargetime` | 분 | 충전 시간. 보통 9\~20분 |

### `curves/<셀>.npz` (사이클별 방전 곡선)

| 배열 | 모양 | 단위 | 뜻 |
|---|---|---|---|
| `Qdlin` | (사이클, 1000) | Ah | 방전 용량을 전압 눈금에 맞춰 보간한 값 (정전류 구간만) |
| `dQdV` | (사이클, 1000) | Ah/V | 방전 dQ/dV |
| `Tdlin` | (사이클, 1000) | °C | 같은 눈금의 온도 |
| `Vdlin` | (1000,) | V | 전압 눈금: 3.5V → 2.0V를 1,000칸으로 (124개 셀 모두 같음) |
| `cycle` | (사이클,) | | 행마다 사이클 번호. **행 번호 대신 이것으로 찾아요** |

### `raw/<셀>.npz` (몇몇 사이클의 원시 측정값)

처음 · 10번째 · 100번째마다 · 마지막 사이클만 남겨요. 위치는 `raw_index`(0부터 셈), 구간은 `raw_offsets`로 잘라요.
(이어 붙인 5개 셀은 두 기록에서 따로 골라서 이음매 앞뒤 사이클이 더 들어 있고, 이음매 뒤로는 100번째마다의 위치가 어긋나요. 항상 `raw_index`로 찾아요.)

| 배열 | 단위 | 뜻 |
|---|---|---|
| `raw_t` | 분 | 사이클 안에서 지난 시간 |
| `raw_V` | V | 전압 |
| `raw_I` | **C-rate** (1C = 1.1A) | 전류. 양수 = 충전, 음수 = 방전. 암페어가 아니에요 |
| `raw_Qc` · `raw_Qd` | Ah | 누적 충전 · 방전 용량 |
| `raw_T` | °C | 온도 |

## 알고 써야 할 점

| 내용 | 어떻게 다루나 |
|---|---|
| b1의 1번째 사이클은 기록이 없어 **모든 값이 0인 줄**로 들어 있어요 | 용량·충전량·저항·온도가 모두 0인 줄은 빼고 봐요 |
| 수명 라벨 규칙이 두 가지예요: b1·b3는 0.88Ah에 닿자 시험을 멈춰 **수명 = 마지막 기록 + 1**, b2는 더 시험해서 **처음 0.88Ah 미만 사이클** | 두 규칙으로 124/124개 셀이 라벨과 정확히 맞아요 |
| 10개 셀은 `policy` 표기와 실제로 잰 전류가 달라요: b3의 `4.8C(80%)-4.8C-newstructure` 4개는 실제 4.36C, b2c12(`4C(31%)-5`)는 둘째 단계가 5.47C, b2 5개는 3.6V 상한에 닿아 둘째 단계 전류가 줄어요 | 충전 조건을 비교할 때는 `policies` 명령이 만드는 `data/processed/policies_cells.csv`의 실제 전류(`c1_real`·`c2_real`)를 써요 ([충전 조건](policies.md)의 '결과' 1번) |
| b2는 250사이클 근처에서 컴퓨터 재시작으로 약 8시간 멈췄어요 | 그 흔적이 깨진 방전 곡선, 범위 밖 용량(1.49·1.54Ah), **약 500분짜리 충전 시간**으로 남아 있어요. b2 이상의 53%가 240\~259사이클에 몰려요 |
| 측정값이 1% 넘게 꺼졌다 돌아오는 **순간 하락**이 19개 셀에 있어요 (b1c0에만 45번) | 용량 추세를 볼 때는 이동 중앙값 등으로 걸러요 |
| 이어 붙인 5개 셀은 이음매에서 용량이 바뀌어요 (3개는 재개 직후 −1.4% 안팎) | `seam_cycle`로 표시해요. 모두 1,177사이클 이후라 첫 100사이클 분석에는 영향 없어요 |
| 방전 곡선에 말이 안 되는 값(-0.01Ah 미만·1.3Ah 초과)이 있는 사이클이 33개 셀에 있어요 | 수명 예측에 쓰는 10·100번째 사이클은 **124개 셀 모두 깨끗해요** |
| b1의 15개 셀은 내부저항이 0으로 빠진 사이클이 1\~3개 있어요 | 0은 결측으로 봐요 |
| 셀 한 종류 · 온도 한 가지 · 방전 조건 한 가지 | 다른 셀이나 실제 사용 조건으로 그대로 넓히기는 어려워요 |

## 검증한 것

- 셀 수와 학습/테스트 나누기는 논문과 같고, 수명 범위(148 \~ 2,237)는 논문의 어림값(150 \~ 2,300)과 비슷해요.
- 초반 100사이클 용량 변화 중앙값 **+0.22%** (논문 +0.2%).
- log Var(ΔQ₁₀₀₋₁₀)와 log 수명의 상관 **r = −0.927** (논문: 강한 음의 상관).
- 곡선·원시 데이터의 j번째 사이클 = 요약표 j번째 사이클: 원시 값이 있는 **1,289/1,289개 사이클 일치** (최대 오차 0.005mAh).
